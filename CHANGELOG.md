## 0.1.0 - 2026-09-11

Initial release.

### Features

- Pure-TUI chess client (ratatui + crossterm): menu, lobby, board, movelist,
  clocks, dialogs, settings, help, game-over screen
- LAN auto-discovery via UDP broadcast — no server, no accounts, no IP typing
- Peer-to-peer games over TCP (NDJSON): invite/accept/decline handshake,
  random color assignment, per-move clock sync
- Full chess rules via the `chess` crate: legality, check, checkmate,
  stalemate, threefold repetition, fifty-move rule, castling, en passant,
  promotion, FEN, SAN/UCI
- Chess clocks: 1+0 / 3+2 / 5+0 / 10+0 presets, increment, timeout detection
- Legal-move hints, last-move and check highlighting, board flip
- Draw offers, resignation, opponent-disconnect handling (win by abandonment)
- Auto-saved standard PGN history with move-by-move replay
- TOML config: player name, piece style, coordinates, hints, default time
  control, board flip
- Multi-process end-to-end driver (`examples/lan_pair.rs`) and 56 tests
